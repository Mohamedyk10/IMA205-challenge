This repository contains my work and solution for the [IMA205 Kaggle Challenge](https://www.kaggle.com/competitions/ima205-challenge-2026/overview), organized as part of the _Apprentissage pour l'image_ (Machine Learning for Image Processing) course at my school.

## 🏅 Results

- **Final Ranking:** 3rd out of 77 participants 🥉
- **Final F1-Score:** 0.7915

_For a deep dive into the methodology, architectures tested, and results analysis, please refer to the **[Final Report](report%20and%20notebooks/)** included in this repository._

## 📁 Repository Structure

- `report and notebooks/`: Contains the Jupyter notebooks used for data exploration, training, and inference, as well as the detailed final project report.
- `submissions/`: Contains the various `.csv` submission files generated by the different methods and models proposed during the competition.

## 🚀 How to Run

If you wish to test the code and reproduce the results, you will need to download the dataset first:

1. Download the dataset from the [competition page](https://www.kaggle.com/competitions/ima205-challenge-2026/data).
2. Extract the downloaded archive.
3. Place the `train/` and `test/` folders directly inside the `report and notebooks/` directory.
4. Run the notebooks !
